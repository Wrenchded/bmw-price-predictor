# BMW Used Car Price Predictor 

A full-stack **Machine Learning** application that predicts the price of used BMW cars in India.

Built as a complete production-style project with **ML + FastAPI + HTML/CSS/Streamlit + Render + Netlify**.

Link : https://bmw-price-predictor.netlify.app/


## ✨ Features

- **Accurate Price Prediction** using Random Forest (R² = 0.995)
- **FastAPI Backend** with proper input validation and Swagger UI
- **Premium BMW-styled Frontend** (dark theme + blue accents)
- **Real-time predictions** via API
- **Ready for Production** – deployed on Render (Backend) and Netlify (Frontend)
- Clean project structure following industry best practices

## 🛠️ Tech Stack

| Layer          | Technology                  |
|----------------|-----------------------------|
| ML Model       | scikit-learn (RandomForest) |
| Backend        | FastAPI + Pydantic          |
| Frontend       | HTML/CSS/Streamlit          |
| Deployment     | Render + Netlify            | 
| Data           | 600 BMW records             |
